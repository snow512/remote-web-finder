# 스펙 관리 규칙

이 폴더는 프로젝트의 기술 참조 문서(스펙)를 관리합니다.
스펙은 데이터베이스 스키마, 기술 스택 결정, 아키텍처, API 설계 및 기타 기술 문서를 다룹니다.

---

## 폴더 구조

```
.madang/categories/specs/specs.md           ← 이 파일 (규칙)

docs/specs/
└── {title}.md                  ← 개별 스펙 파일 (간단한 이름)
```

---

## 관리 규칙

1. **새 스펙:** `{title}.md` 파일 생성 (소문자, 하이픈 구분)
2. **파일명 형식:** `{title}.md` — 날짜 접두사 없음, 번호 접두사 없음
3. **모든 스펙 파일은 YAML frontmatter 헤더가 필수** (아래 템플릿 참조)
4. **스펙은 참조 문서** — 상태 수명 주기가 없음
5. **직접 수정** — 스펙은 살아있는 문서이며, 정보가 변경되면 직접 편집

---

## 스펙 파일 템플릿

```
---
title: {제목}
last-updated: {YYYY-MM-DD}
---

## 개요
(이 스펙이 다루는 내용과 존재 이유)

## 상세

(기술적 세부 사항, 스키마, 다이어그램 등)

## 제약 사항
(한계, 트레이드오프, 비목표)

## 예시
(사용 예시, 샘플 데이터 또는 코드 스니펫)

## 변경 이력
| 날짜 | 변경 내용 |
|------|-----------|
| {YYYY-MM-DD} | 초기 스펙 생성 |
```
